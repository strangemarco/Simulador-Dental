# Simulador Dental 2D Interactivo

Simulador dental 2D desarrollado con **Vue.js**, **Vite**, **JavaScript** y **Phaser 3**.  
El proyecto permite interactuar con una boca en 2D compuesta por 32 dientes, aplicar herramientas odontológicas básicas, detectar caries aleatorias, simular tratamientos, extracciones, sellados, sonidos, puntaje, penalizaciones e historial clínico por diente.

## Tecnologías utilizadas

- Vue.js
- Vite
- JavaScript
- Phaser 3
- Lucide Vue Next
- Web Audio API
- CSS Responsivo
- Vercel para despliegue

## Características principales

- Simulación dental 2D interactiva.
- Boca con 32 dientes.
- Clasificación de dientes: incisivos, caninos, premolares, molares y terceros molares.
- Caries generadas aleatoriamente.
- Dientes sanos, con caries, podridos, tratados, sellados o extraídos.
- Herramientas odontológicas:
  - Explorador
  - Jeringa
  - Limpieza
  - Turbina
  - Diagnóstico de caries
  - Sellado
- Sistema de puntaje.
- Penalización por saltarse el flujo clínico.
- Historial de acciones por diente.
- Sonidos generados con Web Audio API.
- Diseño responsivo para escritorio, tablet y celular.
- Despliegue web mediante Vercel.
